### _Black Hole is an open-source, non-custodial, privacy-focused Bitcoin wallet for Linux that talks only to your own Bitcoin node. It is a fork of [Wasabi Wallet](https://github.com/WalletWasabi/WalletWasabi)._

## Installation Guide
Download the software package for your system and install Black Hole like you would any other software on your computer.
Verify the signature of the package before you install it.

## Advanced Guide
To build Black Hole from source code, follow the [README](https://github.com/Kruwed/BlackHole/blob/master/README.md).

## Requirements
- Ubuntu 22.04+
- Fedora 42+
- Debian 12+
- A Bitcoin node with the RPC interface enabled
