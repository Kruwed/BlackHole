# Security Policy

If a vulnerability does not compromise users' privacy or security, open a [regular GitHub issue](https://github.com/Kruwed/BlackHole/issues/new/choose).
If it does, then take great care with responsible disclosure by reporting a [vulnerability on GitHub](https://github.com/Kruwed/BlackHole/security/advisories/new).

Black Hole is a fork of Wasabi Wallet. If the vulnerability is in code that Wasabi Wallet has too, please report it to [Wasabi Wallet](https://github.com/WalletWasabi/WalletWasabi/security/advisories/new) as well.
